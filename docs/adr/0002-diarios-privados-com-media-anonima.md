# Diários privados, com média anônima das notas

Ninguém vê o diário, as fotos, os textos ou as notas de outra pessoa. A única informação que sai do diário de alguém é a nota, que entra numa média anônima por cachoeira do mapa, mostrada só quando pelo menos 3 pessoas avaliaram. Sem essa média, a busca não teria como mostrar as cachoeiras "mais seguras" ou "mais bem avaliadas" que a pessoa ainda não visitou.

## Consequências

- Cachoeiras particulares nunca entram na média nem aparecem para outras pessoas.
- Com menos de 3 pessoas avaliando, a busca mostra "poucas avaliações" em vez de um número que revelaria a nota de alguém.
